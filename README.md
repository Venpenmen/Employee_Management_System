# EMS 员工管理系统 v1.2.2

Windows x64 本地部署版，包含员工与组织、考勤请假、薪资、通讯公告及数据库管理。

## 安装和运行

发行资产由项目维护者在 GitHub Releases 发布。取得 EMS_v1.2.2_Windows_x64.zip 后，使用随附 SHA256SUMS.txt 核对文件并完整解压。打开 EMS_管理入口.bat，选择 5 初始化、1 启动、7 获取安全模式本机入口码。打开启动输出所示地址的 /local-entry 页面，完成入口授权后用初始化的高层账号登录。选项 2 停止服务。

从 v1.2.1 升级时，保留旧安装和已验证的加密备份。将 v1.2.2 解压到独立目录，在数据库管理页面导入旧版 .emsbk，核对隔离预览后确认切换。重新登录并核对员工、组织、考勤、请假和工资历史。

## 源码构建

在 Windows x64 开发环境使用 Java 17 和 Maven。执行 mvn -f backend/pom.xml clean package 进行源码构建。发行包包含所需的 Java 和 MySQL 运行时。

## 发行候选验收

16 项中 13 项通过、3 项条件验证、0 项失败、0 项阻断。条件验证包括管理菜单人工交互及安全模式一次性入口码登录、真实局域网 TLS 通讯、真实外网 TLS 通讯。三项仍待实测。
