# EMS 员工管理系统

**EMS（Employee Management System）** 是一套面向组织内部人事管理的 Web 系统，围绕员工档案、部门、考勤、请假、薪资和权限管理等日常工作提供统一的操作入口。

当前版本：**v1.2.1** · Windows x64 独立服务器版

## 系统能做什么？

| 功能模块 | 主要用途 |
| --- | --- |
| 员工管理 | 管理员工基本资料、在职与离职信息 |
| 部门管理 | 维护部门及人员归属，支持部门经理管理 |
| 考勤管理 | 记录和查询员工打卡情况 |
| 请假管理 | 处理请假申请及相关审核流程 |
| 薪资管理 | 管理与查看薪资相关信息 |
| 角色与权限 | 根据员工、经理和高层等身份控制可访问的功能与数据 |
| 数据库管理 | 提供备份、导入验证及隔离恢复等维护能力 |

> 不同身份可使用的功能有所区别，具体以系统内实际授权为准。

## ✨ v1.2.1 更新亮点

本次更新重点不是增加大量业务页面，而是让 EMS **更容易部署、更方便维护、运行更稳定**。

### 开箱即用的服务器发行包

- 提供适用于 **Windows x64** 的独立服务器压缩包。
- 发行包内置 **Java 17** 和 **MySQL 8.0** 运行环境，减少手动配置。
- 首次使用时可通过引导初始化高层管理员账号。
- 提供服务器启动、停止与运行状态检查功能。

### 更清晰的网络配置

- 提供**安全模式**和**兼容模式**，适应不同的网络使用场景。
- 默认优先采用本机访问方式。
- 提供局域网及 Sakura FRP 外网访问的配置路径；相关场景仍需按实际环境验证。

### 更方便的数据库维护

- 将数据库管理划分为**基础操作**和**高级迁移**。
- 支持数据库备份、导入前验证和隔离恢复。
- 优化操作界面与信息展示，降低日常维护难度。

### 运行稳定性改进

- 改进 Windows 环境下的临时目录处理。
- 修复部分环境中 MySQL、Java/Tomcat 和 PowerShell 维护进程因临时目录权限不足而无法正常工作的情况。
- 继续完善服务器启动和维护流程。

## 📦 下载与快速开始

**只想安装使用？建议下载 [GitHub Releases 发行包](https://github.com/Venpenmen/Employee_Management_System/releases)，无需自行编译源码。**

1. 下载 `EMS_v1.2.1_Windows_x64.zip`。
2. 将压缩包**完整解压**到独立文件夹，不要在压缩包内直接运行。
3. 按压缩包内的启动入口和引导完成初始化。
4. 使用初始化的管理员账号进入系统。

发行包仅面向 **Windows x64**。首次部署、网络访问和数据库迁移前，建议阅读下方说明文档。

> **源码与发行包的区别：** 本仓库保存的是项目源码；独立服务器 ZIP 额外包含运行库、启动脚本及必要文件。仅下载仓库源码并不等于获得可直接运行的免安装版本。

## 🔄 数据备份与版本升级

数据库涉及员工与业务数据，**升级前请先备份，不要直接覆盖正在运行的安装目录或活动数据库**。

- **v1.2.0 → v1.2.1：** 备份导入验证已通过；完整切换、重启和回滚流程仍需进一步验证。

## 🛠️ 技术架构与源码构建

项目主要使用 **Java 17、Spring Boot、MySQL 8.0、Flyway**，前端使用 Web 页面与 JavaScript。

源码目录：

- `backend/`：Spring Boot 后端。
- `frontend/`：前端页面及资源。
- `server-complete-rc2/`：v1.2.1 服务器管理脚本。
- `server/`：保留的旧版脚本，**不要用作 RC2 启动入口**。
- `docs/`：部署、升级、安全与验收文档。

开发者可在配置好 Java 17 和 Maven 后，从仓库根目录执行：

```powershell
mvn -f backend/pom.xml test
mvn -f backend/pom.xml package
```

上述命令生成后端构建产物，**不会自动生成完整的 Windows 独立服务器发行包**。服务器脚本还依赖与版本匹配的 JAR、构建清单及运行库。

## ⚠️ 使用提醒

- 本项目包含人员与业务数据管理能力，**不要将真实员工数据直接暴露到公网**。
- 兼容模式仅建议用于虚构或脱敏数据；涉及真实数据时应采用更严格的访问控制。
- 局域网、Sakura FRP 外网访问、完整升级切换及部分回滚场景尚未完成全面验收。
- 不要向公开仓库提交密码、密钥、数据库备份、运行数据或日志。
- v1.2.2 的通讯功能不属于本次 v1.2.1 发行范围。
