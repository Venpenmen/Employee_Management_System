# v1.2.1 演示数据库补丁

此目录提供原 v1.2.0 的独立演示数据包，供 v1.2.1 测试和功能展示使用。它**不是程序更新补丁**，不会自动修改任何数据库。

## 文件

- `EMS_v1.2.0_DemoData.zip`：原始演示数据包，内含加密的 `.emsbk`、40 个演示账号、备份口令、操作说明及校验清单。
- `EMS_v1.2.0_DemoData.zip.sha256`：原始 SHA256 校验值。

## 使用步骤

1. 下载 ZIP 并校验 SHA256。
2. 解压后阅读其中的 `DEMO_DATABASE_GUIDE.md`。
3. 在**独立测试实例**中先备份当前数据库，并完成恢复验证。
4. 按数据库管理界面的导入流程，选择 ZIP 中的 `.emsbk`，先进行隔离校验和预览，再决定是否确认导入。
5. 使用 ZIP 中的演示账号清单验证登录、角色和权限。

**注意：** 此包含公开的演示账号及口令，只能用于虚构或脱敏数据。切勿将其导入正式生产数据库，也不要将演示账号用于真实业务。原包曾在 v1.2.0 验证；v1.2.1 的完整导入和升级验收仍需在独立实例中确认。
