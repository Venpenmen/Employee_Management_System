# 已知边界与发布门禁
- 升级验证应只读保护历史安装；原版本升级测试使用独立的合成旧安装，不执行真实生产迁移。
- 本地构建与验证不自动推送远程分支或发布正式 Release；部署与发布应遵循独立审核流程。
- 不新增部门清空或手动审批转交。单一高层请假沿用原系统自动通过规则，不等同于允许人工自批。
- 候选仅用于可信环境的虚构数据测试。高层数据库管理远程要求实际HTTPS；代理部署需单独审查，不能仅靠伪造X-Forwarded头信任来源。
- 加密备份512MiB、解包4GiB限制；大数据量性能与恢复耗时需另行压测。
- 手工IDEA调试进程不能由停止BAT自动接管；受控切换使用有归属记录的dev运行器。
- 用户备份口令遗失无法恢复；自动备份的DPAPI恢复密钥不适合直接跨主机复制。
- 中断恢复仅处理具有有效归属日志的任务，未知状态保留现场；不会静默重建空库或强制结束未知进程。
- 未来更高版本迁移须追加SQL并测试；本候选不能被当作已验证的v1.2.1整合发行版。

- 当前统一验收入口是 launcher/build-release.ps1 和 launcher/test-server.ps1。保留的历史 test-portable/test-sync 等辅助脚本仍对应旧发行命名/独立同步工具，不作为当前版本可直接运行的验收入口；未将它们的测试结果计入本版通过项。
- 清理/证据保存使用受管理任务目录；故障测试失败记录与最终通过记录分别保留，不把预期故障任务的失败状态改为成功。
