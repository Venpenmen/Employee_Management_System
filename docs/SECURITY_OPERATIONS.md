# rc2安全功能与受控运维

## 权限与接口

- 全角色：GET /security、GET /api/security/notifications、POST /api/security/notifications/{id}/read，仅本人通知；高层可筛选其管理通知中的目标员工/事件/日期/未读。
- SSE：GET /api/security/events，当前正常会话；GET /api/security/session-status仅补查当前Cookie身份，不支持指定他人工号订阅。
- 员工/经理：POST /api/security/requests、/{id}/cancel；不能审批或查看他人申请。
- 高层：POST /api/security/secondary、authorize、requests/{id}/approve、accounts/{id}/reset、accounts/{id}/unfreeze。
- 匿名重置：GET /security/reset、POST /api/security/reset；仅线下核验交付的30分钟一次性码，匿名会话CSRF，来源限流及统一失败提示。
- 临时登录：只允许/security/temporary-password、POST /api/security/temporary-password和/logout；不能借API、直接URL或普通改密绕过。

所有写入使用_csrf或X-CSRF-Token；权限以服务端当前账号/会话复核为准。仅RESET和UNFREEZE需要二级密码，原数据库维护仍沿用原登录密码验证，不增加二级要求。

## 已确认策略

二级密码8位起、72 UTF8字节内，字母数字，与登录密码不同；独立BCrypt。二级授权绑定操作/目标/当前会话/凭证版本，2分钟一次性。二级连续5次错误暂停15分钟，不冻结高层登录账号。

员工自行重置：高层线下独立核验，批准后单次显示随机码，线下交付，30分钟一次性。临时密码24小时、5次错误后需重新签发；正常改密与重置不自动解冻或解除其他业务限制。申请7天到期，仅本人一条有效申请。密码/码/授权均不存localStorage、不进URL、不在通知中展示。

10分钟3次替换警告、6次替换安全冻结，集中配置ems.security.window-minutes/warning-threshold/freeze-threshold；高层豁免异常警告与冻结但仍接收会话替换推送。只计成功登录替换其他有效会话，不以IP/UA作设备唯一ID；同Cookie再认证不计数并重连SSE。事件和计数在账号事务内，通知提交后推送，数据库始终作最终鉴权。

## 二级密码遗忘：受控恢复设计，不是自动接口

本版没有二级密码找回/重置后门。普通登录密码本身不能授权清除二级凭证。

1. 由负责人提出有编号的恢复请求，独立线下验证高层身份及操作权限；至少一名独立复核人确认，记录范围、原因、时间和责任人。
2. 明确停机窗口及数据写入截止点，由授权人员仅通过目标安装自身停止入口处理，核对PID/启动时间/路径，禁止操作未知进程。
3. 使用既有加密备份及隔离恢复路径建立并验证恢复点，核对字段摘要与关键业务关联。
4. 本版本不交付未经批准的清凭证命令。具体维护变更必须另行审批、在隔离副本演练：仅处理指定高层二级凭证及该凭证版本的操作授权，并使目标会话失效；不改登录密码、角色、业务数据或其他人凭证。
5. 将批准的维护脚本、审批单及执行审计保存在受控位置；检查不能恢复旧授权/会话，验证高层重新设置二级密码；任何身份/归属不明停止恢复。
6. 无法完成独立核验或没有经过验证的备份时，不恢复，升级为人工应急处理。此设计不等于已实施或已验证生产恢复工具。

## 通知及运行边界

当前SSE为单实例内存分发，事件/通知数据库持久化，断线重连和休眠恢复补查。服务重启/失效需重新登录；同Cookie窗口共享身份，不是物理设备指纹。公网代理信任配置、真实双设备、HTTPS建设需单独验收，不操作FRP。

服务器应保持可信时间；所有持久化过期及滚动窗口使用数据库时间，不擅自修改系统时钟。调试不能打印密码、授权、Cookie或会话摘要。关闭时先终止SSE连接，避免持续连接拖延正常停机。

重置码丢失/过期：高层线下重新核验后使用申请记录“重新签发”按钮（POST requests/{id}/reissue），旧码立即作废；不读取旧码，不扩大二级范围。正常已知旧密码改密会撤销未使用自行重置码及已批准资格。登录密码与二级密码不得互相复用。
