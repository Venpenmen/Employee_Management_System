# 高层整库备份与恢复
高层菜单“数据库管理”提供导出、隔离校验、确认导入、任务状态和下载。普通员工、经理即使直接调用接口也被拒绝。

## 身份与口令
每次导出、导入预览、确认切换均重新验证当前高层密码和最新角色/账号/会话。授权120秒、单次有效，绑定操作和任务，重放、错操作、过期均拒绝。错误验证有次数限制，CSRF持续有效。
备份口令独立于登录密码，12–256字符，导出须确认；服务器不保存用户口令。忘记口令无法解密，应离线妥善保存。

## 格式与一致性
EMSBK001格式，PBKDF2-HMAC-SHA256 600000轮、16字节随机盐，AES256-GCM、随机12字节nonce及128位认证标签。加密负载含格式/程序/结构版本、列及索引/约束信息、业务表数据、逐表记录数与SHA256。
导出使用同一REPEATABLE READ快照流式读取，行数和摘要在该快照中计算，不用导出后另查的行数冒充一致性证明。
完整业务备份包含原17张业务表及账号BCrypt哈希；不包含account_active_session、Flyway运行历史、数据库连接凭据、原始会话令牌或服务器密钥。恢复只运行受信任迁移及参数化DML，不执行上传文件中的任意SQL。
文件上限512MiB，解包内容上限4GiB，限制条目/路径/字段类型。口令错误、认证标签错误、篡改、不兼容版本、未知结构或关联异常均不切换原库。

## 确认导入
1. 重新验证当前高层，上传备份及口令；恢复到独立的新数据库，检查结构、记录数、哈希和关系。预览不影响当前库和会话。
2. 显示版本、兼容结果和各表记录数。备份必须有有效高层账号；确认时再次验证当前高层，并验证备份内高层工号和密码。
3. 维护窗口排空请求，先自动加密备份当前库，并实际恢复到临时验证库核对；通过后才停止本模式自有应用。
4. 原子切换数据库指针并受控重启，健康检查及导入审计通过才标成功。失败恢复旧指针；旧库及备份保留。
5. 所有本模式旧会话失效，使用备份中的账号重新登录。不是员工合并，不保留当前账号来修改备份数据。其他模式与历史服务不受影响。

本机自动备份生成随机恢复口令并以当前Windows用户DPAPI保护，recovery.key.dpapi与密文分开保存，不进入公开导出包。仅适用于同一主机/用户；跨机器迁移请使用自设口令的网页导出。
CLI backup-database及verify-restore共用同一引擎。明文SQL恢复入口已禁用；旧物理安装通过受控冷副本升级转换。
手工IDEA进程不受脚本接管，自动切换要求本模式运行器拥有进程身份；IDEA可调试业务、导出和预览，受控重启验收使用dev运行器。
