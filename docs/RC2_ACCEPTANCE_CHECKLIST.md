# rc2正式发布前人工验收

以下不以本机自动化冒充：

- [ ] 干净Windows10/11 x64标准用户，无Java/MySQL，断网解压运行及双击BAT。
- [ ] 真实第二台设备/手机收到SSE失效通知，断网/休眠恢复后补查正确。
- [ ] 用户自行生成真实旧版备份并验证恢复，在停止写入截止点后按升级指南切换；本轮未操作真实数据。
- [ ] 原账号、部门/职位、经理任命/审批、薪资、考勤、请假和档案人工抽查。
- [ ] IDEA GUI实际选择JDK17、环境变量、点击Debug验证；自动主类启动不是GUI证明。
- [ ] HTTPS或等效加密与网络访问控制；公网FRP目标及客户端地址信任配置单独核验。
- [ ] 按 SAKURA_FRP_HTTPS_ADAPTATION.md 在独立测试部署验证真实证书、raw TCP/TLS 全链路、Secure Cookie、SSE、CSRF 和伪造转发头拒绝；本机 TLS 边界测试不代替此项。当前 HTTP 启动器尚未适配 TLS，不直接修改现有服务。
- [ ] 高层线下核验及凭证单次交付流程培训；二级密码遗忘应急责任人及授权流程确认。
- [ ] 已知限制、自动化报告、失败修复和恢复路径评审；用户明确批准后才正式发布。

未完成这些项目不宣称正式上线验收通过，不自动覆盖正式安装或推送远程。
