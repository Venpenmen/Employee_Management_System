# EMS v1.2.1 网络模式内部测试说明

2026-10-29续做修订：下面是旧RC2测试开关的历史操作说明。新候选源码已禁止普通安装仅凭EMS_NETWORK_MODE=compatibility跳过传输检查；必须同时证明副本位于本任务受管理目录，任务作用域、运行状态、owner PID/启动时间/可执行路径匹配。无有效证明直接拒绝不安全模式启动。尚未完成三种网络模式与GUI整合，不按下列历史流程给普通发行包启用兼容模式；未修改当前运行RC2或FRP。

此功能仅针对 v1.2.1-next RC2 的独立测试分支，不适用于正式发布。

## 操作

1. 在服务器主机双击根目录的「网络运行模式设置.bat」。
2. 选择「安全模式」或「内部测试兼容模式」，确认并保存。
3. 正常停止 EMS 服务后重新启动。切换不影响现有数据，也不改变 Sakura Frp 映射。
4. 安全模式（默认）：公网 HTTP/不可信代理不能访问数据库管理，服务器本机回环访问和可信 HTTPS 仍按原规则处理。
5. 内部测试兼容模式：临时跳过数据库管理的 HTTPS 传输检查。通过原有 Sakura Frp 地址访问数据库管理时，仍要求高层账户、会话和二次密码验证。
6. 完成测试后切回安全模式并正常重启服务器。

配置保存于 `server/network-mode.json`，只允许 `secure` 或 `compatibility`。文件不存在时默认安全模式。配置变更必须重启 EMS 后生效。

## 限制

- 兼容模式存在公网 HTTP 传输敏感数据的风险，仅使用虚构/隔离测试数据库。
- 数据库导入和恢复可能覆盖数据；必须先完成备份，并通过现有二次确认流程。
- 切换网络模式不自动切换数据库、不执行数据库恢复、不自动停止服务。
- 现有运行中的 RC2 不受本分支源码修改影响；必须使用本分支重新构建的测试版本才具有新开关。
