# 历史 BAT 入口归档（v1.2.0 系列）

本目录保存曾位于仓库根目录、调用 server/*.ps1 的六个通用入口。v1.2.2 当前统一管理入口为 EMS_管理入口.bat，调用 scripts/rc2/RC2_*.bat，再由 server-complete-rc2/*.ps1 执行。

仅移动文件，不修改原 BAT 内容，不删除 server/ 旧脚本，不改变 main、v1.2.2 标签或冻结发行包。归档 BAT 使用 %~dp0 定位旧 server 目录，移动后不能从归档位置直接运行；仅供历史追溯。

准备开发数据库.bat 与便携模式 BAT 仍服务于开发/兼容流程；监控服务器.bat 暂时保留。

归档日期：2026-11-13；分支：develop。
